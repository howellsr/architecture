## Who does what

| Role | Responsibility |
| --- | --- |
| **Service owner / SRO** | Owns the security risk of the service and accepts residual risk within appetite |
| **Delivery team** | Builds security in: threat models, secure code, scanning, fixing vulnerabilities |
| **Security architects** | Advise teams, review designs, maintain security patterns and guardrails |
| **Security operations centre** | Monitors, detects and responds to threats across Defra |
| **Senior Information Risk Owner (SIRO)** | Owns information risk for the department and accepts risks beyond service owner authority |
| **Chief Information Security Officer** | Sets security policy and risk appetite |

## Standards we align to

- [Secure by Design](https://www.security.gov.uk/policy-and-guidance/secure-by-design/) - the government approach for digital services
- [Secure by Design artefact library](https://github.com/co-cddo/SbD) - reusable security patterns, blueprints, checklists and threat models from across government
- [Government Cyber Security Strategy](https://www.gov.uk/government/publications/government-cyber-security-strategy-2022-to-2030)
- The NCSC [Cyber Assessment Framework](https://www.ncsc.gov.uk/collection/cyber-assessment-framework), assured through GovAssure
- [Government security classifications](https://www.gov.uk/government/publications/government-security-classifications)
- [NCSC cloud security principles](https://www.ncsc.gov.uk/collection/cloud/the-cloud-security-principles)
- [OWASP Application Security Verification Standard](https://owasp.org/www-project-application-security-verification-standard/)
