# Templates

<p class="lead">Lightweight templates for the most common architecture artefacts. Copy them into your repository and adapt as needed.</p>

| Template | Use it when |
| --- | --- |
| [Architecture decision record](adr.md) | You make a significant design decision |
| [TDA submission](tda-submission.md) | You are bringing work to the [Technical Design Authority](../tda.md) |
| [Guardrail exception request](exception-request.md) | You cannot meet a Must guardrail |
| [Threat model](threat-model.md) | You are [threat modelling](../../security/threat-modelling.md) a service or change |

Each template is plain Markdown so it can live in your repository next to your code. Select **Edit this page** at the top right of any template to see its source.
